Política de Privacidade

Última atualização: 20 de outubro de 2026.

Quem trata os dados

O BarberShop AOS, em Bissau, Guiné-Bissau, trata os dados descritos nesta política para gerir pedidos de marcação e o funcionamento do site. Para questões de privacidade, contacta-nos pelo telefone/WhatsApp +245 955 115 048.

Dados de marcação

Quando pedes uma marcação, recolhemos o nome, número de telefone, salão, serviço, profissional, data e hora pretendidos e forma de pagamento selecionada. Estes dados são usados para registar e gerir o pedido, verificar disponibilidade e contactar-te sobre a marcação. O pedido fica disponível à equipa autorizada da barbearia.

Mensagens

O site pode enviar os detalhes da marcação ao gerente do salão por WhatsApp, através do fornecedor configurado pela barbearia. Se o envio automático não estiver disponível, o site pode permitir que abras o WhatsApp para enviar o pedido. As mensagens passam a estar sujeitas também às políticas do WhatsApp e do fornecedor de envio utilizado.

Integração com TikTok

Se o titular de uma conta TikTok autorizar a integração, o site usa a API do TikTok para consultar informações básicas e estatísticas do perfil, bem como vídeos autorizados, com a finalidade de apresentar publicações e informações públicas da barbearia. O site não publica, edita nem apaga conteúdo no TikTok. Os tokens de autorização são guardados no Supabase, numa tabela privada, para manter e renovar a ligação. Imagens obtidas das redes podem ser guardadas no armazenamento do Supabase para serem exibidas no site.

Prestadores e armazenamento

O site utiliza o Supabase para base de dados, autenticação, armazenamento e funções de servidor. As informações necessárias para apresentar conteúdo de redes sociais são partilhadas com as APIs correspondentes quando a integração está ativa. Não vendemos os dados de marcação.

Conservação e segurança

Os dados são mantidos nos sistemas usados pela barbearia enquanto forem necessários para gerir as marcações e operar o site, ou até serem removidos pela equipa autorizada, sem prejuízo de obrigações aplicáveis. Aplicamos controlos de acesso no serviço de base de dados, mas nenhum sistema ligado à Internet pode garantir segurança absoluta.

Os teus pedidos

Para pedir acesso, correção ou remoção dos dados associados à tua marcação, contacta a barbearia pelo número acima. Poderemos pedir informações suficientes para localizar o pedido e confirmar que és a pessoa a quem os dados dizem respeito.

Alterações

Esta política pode ser atualizada quando as funcionalidades ou práticas de dados mudarem. A versão atual estará publicada nesta página.
